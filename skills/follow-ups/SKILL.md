# Follow-ups

> If `job-search/profile.md` does not exist yet, run the job-hunt-onboarding skill first.

Turn accepted invites and replies into conversations, and nudge quiet threads at the right time.

## Steps
1. Read the outreach log and the jobs tracker. If a browser or Gmail is connected and the user agrees, check for new accepts and replies.
2. Build the due list:
   - Accepted invite, no message yet: send a first warm message within 1 to 2 days.
   - Recruiter replied: answer the same day.
   - Applied, no answer after 7 to 10 days and a contact exists: one gentle nudge.
   - After an interview: thank-you the same day; nudge after the promised date passes.
   - Two nudges without answer: stop and mark as cold.
3. Draft each message from `references/follow-up-templates.md`. Show drafts, wait for approval, then send or hand them over.
4. Update statuses and next follow-up dates in the trackers.

## Rules
- First ask whether they have something relevant. Offer the CV only if they say yes.
- Never guilt the other side ("you didn't answer"). Keep it light.
- Respect the user's tone corrections and save the improved wording to the profile's working templates.

## Language and style (always)
- Talk to the user in Hebrew unless they write in another language.
- Never use em dashes. Use commas, colons or separate sentences.
- Do not start a Hebrew line or bullet with an English word; it breaks right-to-left display. Rephrase so the line starts in Hebrew.
- Avoid Latin variables or math notation inside Hebrew lines.
- Be direct and short. No preamble, no restating the request.

## Safety rules (never break)
- Send, submit, post or invite only after the user approves that specific action or batch in chat.
- Never type passwords or verification codes. Ask the user to log in themselves.
- Never bypass CAPTCHA, bot protection or rate limits. If a site blocks automation, stop and hand the user a clickable list to do it manually.
- Never invent experience, numbers, titles or degrees. Use only what the user said or what is in their files.
