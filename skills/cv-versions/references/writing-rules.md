# CV writing rules

## Structure (one page)
1. Header: name, target title for this track, city/area, phone, email, LinkedIn.
2. Metric cards (3-4): only real numbers the user gave. Label in sentence case, starting with a capital letter in English.
3. Profile: 3 sentences. Who, strongest proof, what they bring to this track.
4. Recognition (optional): awards as small badges.
5. Experience: newest first. Older roles (7+ years ago) compressed to one line or one bullet.
6. Skills grouped by theme (2-3 groups), as short items.
7. Education, military service (common in Israel, keep short), languages.

## Copy rules
- Clear, concise, consistent: the same term for the same thing in every version.
- No unexplained abbreviations (write "Accounts Payable", not "AP").
- No filler ("results-driven", "passionate", "dynamic"). Replace with a fact.
- Dates as years only unless the user wants months. No reasons for leaving.
- Do not include salary, ID number, marital status, children, age or photo unless the user explicitly asks.
- Do not include company-internal data the user prefers to keep private.
- English: every line and label starts with a capital letter.
- Hebrew: nominal phrasing, few "אני" sentences; numbers as digits.

## Track emphasis examples
- Manager track: scope, people, budgets, process change, cross-team work.
- Hands-on track: tools, systems, problems solved, speed and quality.
- Customer-facing track: accounts, retention, satisfaction, communication.
- Entry/return-to-work track: transferable skills, reliability, learning speed, availability.

## Consistency check before delivery
- Same numbers in all versions.
- One page each.
- File names and track names match the profile's CV map.
