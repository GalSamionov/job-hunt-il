# Recruiter outreach

> If `job-search/profile.md` does not exist yet, run the job-hunt-onboarding skill first.

Contact the people who hire: in-house recruiters, HR, and placement agencies. Warm, short, no pressure.

## Who to contact
- Default: in-house recruiters and HR people at target companies. Not senior executives, unless the user asks.
- Placement agencies that specialize in the user's field.
- People the user already knows at the company (ask the user; referrals beat cold outreach).

## Steps
1. Read the profile (tracks, privacy, approved message, daily cap). Read the outreach log to avoid contacting anyone twice.
2. Build a target list: companies hiring for the user's tracks (from the job round and the tracker), then recruiters there. On LinkedIn, search the company's people page with keywords like talent, recruit, HR, גיוס, משאבי אנוש. Keep name, title, company, profile link.
3. Draft notes from `references/message-templates.md`, personalized with name and company. LinkedIn connection notes: up to 300 characters.
4. Show the batch (names, companies, the exact note) and wait for approval.
5. After approval send one at a time at a human pace, or hand the user the list to send. Respect the daily cap (default 15 to 20 per day) and send only Sunday to Thursday.
6. Log each contact (name, company, link, date, message variant, status "sent") in the outreach log.

## Rules
- Never attach a CV to someone who did not ask for it.
- Never mention what the profile marks as private.
- Do not describe the former employer negatively; use the neutral description from the profile.
- Stop if LinkedIn shows a warning or limit, and tell the user.

## Language and style (always)
- Talk to the user in Hebrew unless they write in another language.
- Never use em dashes. Use commas, colons or separate sentences.
- Do not start a Hebrew line or bullet with an English word; it breaks right-to-left display. Rephrase so the line starts in Hebrew.
- Avoid Latin variables or math notation inside Hebrew lines.
- Be direct and short. No preamble, no restating the request.

## Safety rules (never break)
- Send, submit, post or invite only after the user approves that specific action or batch in chat.
- Never type passwords or verification codes. Ask the user to log in themselves.
- Never bypass CAPTCHA, bot protection or rate limits. If a site blocks automation, stop and hand the user a clickable list to do it manually.
- Never invent experience, numbers, titles or degrees. Use only what the user said or what is in their files.
