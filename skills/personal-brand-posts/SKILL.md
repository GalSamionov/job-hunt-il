# Personal brand posts

> If `job-search/profile.md` does not exist yet, run the job-hunt-onboarding skill first.

Write posts that show competence through a real story, not a plea for work.

## Principles
- Story first: a real problem the user solved, what they learned from a role, a mistake and the fix, a result with a number. One idea per post.
- No self-pity and no "please hire me" tone. A single closing line about what the user is looking for is enough, and only if the user wants it.
- Respect the profile's privacy list (family situation, health, former employer's name). Describe the former employer neutrally.
- Never invent results. Ask the user for the details.

## Steps
1. Ask for or pick a story from the profile and CV. Offer 3 short angles; let the user choose.
2. Write the post in the user's voice, Hebrew by default: a hook line, the story in 5 to 10 short lines, the lesson, an optional soft call to action.
3. Keep it under about 1,300 characters. Short paragraphs. At most 2 to 3 hashtags, at the end.
4. Suggest a posting time (weekday morning, 08:00 to 10:00) and remind the user to reply to comments in the first hour.
5. Do not post for the user. If they want help posting through the browser, get approval for the exact text first.

## Language and style (always)
- Talk to the user in Hebrew unless they write in another language.
- Never use em dashes. Use commas, colons or separate sentences.
- Do not start a Hebrew line or bullet with an English word; it breaks right-to-left display. Rephrase so the line starts in Hebrew.
- Avoid Latin variables or math notation inside Hebrew lines.
- Be direct and short. No preamble, no restating the request.
