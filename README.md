# job-hunt-il · סוכן חיפוש עבודה בעברית

סוכן שמנהל חיפוש עבודה מלא בתוך קלוד, לכל מחפש עבודה בישראל, בכל תחום.

## מה יש בפנים
| יכולת | מה היא עושה |
|---|---|
| אונבורדינג | מסלול כניסה מודרך: חיבורים, פרופיל, קורות חיים, מעקב וסבב ראשון |
| הקמת פרופיל | שיחת היכרות ששומרת מסלולי משרות, אזור, שכר, ומה לא להביא |
| גרסאות קורות חיים | גרסה לכל מסלול, בעברית ובאנגלית, בעמוד אחד |
| סבב משרות יומי | משרות חדשות ורלוונטיות בלבד, עם גרסת קורות החיים לכל משרה |
| פניות למגייסים | איתור מגייסים, נוסח שעובד, מכסה יומית |
| פולואפים | תזכורות ונוסחים חמים למי שאישר או ענה |
| מעקב | טבלת משרות וטבלת פניות |
| שיחה עם מגייס | תשובות מוכנות, שכר, ושאלות שחשוב לשאול |
| הכנה לראיון | לפי המשרה והחברה |
| מיתוג אישי | פוסטים בסגנון סיפור ללינקדאין |
| יום חיפוש | פקודה אחת שמריצה את כל השגרה היומית |
| העיר | Job Hunt: המשחק. עיר פיקסלים אישית שבה כל בית הוא תחנה בחיפוש, והמשתמש מאשר או מדלג |

## העיר: Job Hunt המשחק
[לנסות את ההדגמה בדפדפן](https://galsamionov.github.io/job-hunt-il/)

חמישה בתים, חמישה סוכנים: איתור, קורות חיים, פניות, מעקב וראיונות. כל יום הוא יום אמיתי, וכל כניסה היא סבב שפותח במה שהשתנה מאז הקודמת.

- **בבתים:** מחליקים כרטיסי משרה, מתאימים גרסת קורות חיים לכל משרה, מחתימים מכתבים, מצלצלים בפעמון למי שמחכה לתזכורת, ונלחמים בשאלות ראיון. יש גם תצוגת רשימה למי שרוצה מהר.
- **ברחוב:** העיר עצמה היא התפריט. סוכן שעומד מחוץ לבית מחכה עם עבודה, ובכל רגע יש ברחוב לכל היותר שני אירועים, הכי חשובים קודם. מה שקרה בנתונים מופיע בעיר: מגייסת שענתה, דוור עם מה שהסוכן הגיש, מודעת ראיון, מעטפה של תשובה שלילית (שנסגרת ונותנת כוכבים), והצעת עבודה.
- **העיר גדלה** רק מהתקדמות אמיתית. כוכבים קונים רק כובעים וקישוטים.
- **הסוף:** הצעה שהתקבלה מסיימת את המשחק עם סיכום המסע וכרטיס לשיתוף.
- **ביצוע:** מה שמחליטים בעיר, הסוכן מבצע. משרה שמתאימה בבירור לכללים מוגשת לבד, לפי הרמה שהמשתמש בחר באונבורדינג. העיר יכולה להפעיל את הסוכן מיד, ויש ריצות קבועות בבוקר, בצהריים ובערב.

**שתי דרכים לחבר את העיר לנתונים אמיתיים:**
- **עם Claude והפלאגין הזה:** בסוף האונבורדינג הסוכן מקים עיר פרטית בתוך Claude של המשתמש, לפי קורות החיים והמסלולים שהגדיר. כל בוקר כותבים "בוקר טוב, תמלא לי את העיר להיום", ואחרי ההחלטות "תריץ את מה שאישרתי בעיר".
- **עם ChatGPT או עוזר אחר:** מדביקים לעוזר את [פרומפט ההקמה](prompts/assistant-setup.md), ובעיר הציבורית לוחצים "לחבר לנתונים שלי". העוזר מחזיר קובץ יום שמדביקים בעיר, וההחלטות חוזרות אליו בהעתק והדבק. הנתונים נשמרים רק במכשיר של המשתמש.

הגרפיקה של העיר: Kenney (kenney.nl), רישיון CC0. הפונט: GNU Unifont.

## התקנה

**באפליקציית קלוד (דסקטופ):**
1. מורידים את הקובץ [`dist/job-hunt-il.plugin`](dist/job-hunt-il.plugin) (לוחצים עליו ואז על כפתור ההורדה).
2. פותחים את הקובץ באפליקציית קלוד, או גוררים אותו לשיחה, ומאשרים את ההתקנה.
3. פותחים שיחה חדשה וכותבים: "איך מתחילים".

**בקלוד קוד:**
```
/plugin marketplace add GalSamionov/job-hunt-il
/plugin install job-hunt-il@job-hunt-il
```

## רוצים את הסוכן המלא?
הפלאגין עושה את העבודה לבד. מי שרוצה את הסוכן כמו שאני מריץ אותו, מחובר לדפדפן ולחשבונות, מותאם לתחום ולפרופיל, עם טבלאות מעקב ושגרה יומית, מוזמן לסשן הקמה משותף. פנו אליי בלינקדאין.

## איך מתחילים
אחרי ההתקנה כותבים לקלוד: "איך מתחילים". הסוכן יעביר אותך שלב אחר שלב, בערך 30 עד 45 דקות.

## כללי יסוד
- כל שליחה, הגשה או הזמנה מבוצעת רק באישור המשתמש.
- אין הקלדת סיסמאות. המשתמש מתחבר בעצמו.
- אין עקיפה של בדיקות בוטים או CAPTCHA. אם אתר חוסם, הסוכן מכין רשימה והמשתמש מגיש ידנית.
- אין המצאת נתונים בקורות חיים או בפניות.

## מה מומלץ לחבר
- דפדפן (Claude in Chrome או הדפדפן המובנה) ללינקדאין ולוחות דרושים
- Gmail ויומן Google לפולואפים ולראיונות (לא חובה)

## איפה נשמרים הקבצים
בתיקיית העבודה, תחת `job-search/`: הפרופיל, קורות החיים, ורשימות הפניות.
